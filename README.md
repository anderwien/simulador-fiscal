# Simulador Fiscal

Simulador de IRPF y cuotas de Seguridad Social para España (empleados y autónomos), construido con React, TypeScript, Vite y Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Despliegue

Se despliega automáticamente a GitHub Pages mediante GitHub Actions en cada push a `main`.
